Permission and privacy: Only capture traffic on your own device or a network for which you have explicit authorization. The app stores packet metadata, not full payload contents. HTTPS contents remain encrypted.

Windows setup checklist

  1. Install the official Npcap driver from npcap.com.
  2. Restart the terminal after installation.
  3. If capture fails with a permission error, close VS Code and reopen it using Run as administrator.
  4. Choose the active Wi-Fi or Ethernet interface and start capture.

If live capture is unavailable, PCAP upload remains usable without a live capture driver.
